# Plan: Full Unit Testing for KIM Research Assistant

## Overview
Add automated unit tests for the application logic using Mocha/Chai test framework.

## Steps

### 1. Install Test Dependencies
```bash
npm install --save-dev mocha chai
```

Add test script to package.json:
```json
"test": "mocha"
```

### 2. Create Test Structure
Create `tests/` directory with:
- `tests/unit/` - Unit tests
- `tests/fixtures/` - Test data

### 3. Write Unit Tests

#### TF-IDF Utilities (`tests/unit/tfidf.test.js`)
- `tokenize()` - Test tokenization, filtering, case normalization
- `buildDocFreq()` - Test document frequency calculation
- `tfidfEmbed()` - Test TF-IDF vector generation
- `cosineSim()` - Test cosine similarity (identical, orthogonal, high similarity cases)

#### Core Logic (`tests/unit/core.test.js`)
- `initVectors()` - Test vector initialization
- `findTopK()` - Test top-k document retrieval
- `calculateConfidence()` - Test confidence scoring (high/medium/low)

#### Response Generation (`tests/unit/response.test.js`)
- `generateResponse()` - Test response template selection

### 4. Run Tests
```bash
npm test
```

## Test Coverage Goals
- All Pure Functions: tokenize, buildDocFreq, tfidfEmbed, cosineSim
- All Core Functions: initVectors, findTopK, calculateConfidence, generateResponse
- Edge cases: empty strings, single tokens, large inputs
